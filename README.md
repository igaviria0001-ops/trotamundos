# Trotamundos

Juego para aprender los lugares reconocidos del mundo practicando: ubicar en el globo, raspar fotos, armar mapas, pintar banderas y mucho más.

Las fotos vienen de [Wikimedia Commons](https://commons.wikimedia.org) con licencias libres; el autor y la licencia de cada una están en `fotos/creditos.json` y dentro del juego.

## Carpetas
- `tools/fotos/` — lista de lugares y scripts que bajan datos y fotos (corren en GitHub Actions).
- `fotos/` — fotos elegidas (WebP) y créditos.
- `src/` — código del juego.
